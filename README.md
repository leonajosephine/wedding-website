# Wedding Website

This is a wedding website built with [Next.js](https://nextjs.org). It includes a simple, elegant front-end for sharing wedding details with guests and a RSVP. 

## Features

- Beautiful responsive design 💌
- Wedding details and information for guests 💒
- Built with Next.js and React 🌿
- Easy to customize and deploy 🌟

## Getting Started

### Prerequisites

Make sure you have [Node.js](https://nodejs.org/) installed on your machine.

### Clone the repository

```bash
git clone https://github.com/leonajosephine/wedding-website.git
cd wedding-website
```

### Install dependencies

```bash
npm install
```

### Run the development server

```bash
npm run dev

pnpm dev
```

Then open [http://localhost:3000](http://localhost:3000) in your browser.

## Project Structure

- `app/` — main application pages and layout
- `public/` — static assets like images and icons
- `components/` — reusable UI components

## Editing the site

You can customize the website by editing the files inside the `app/` directory and updating any shared components or styles.

## Deployment

This project can be deployed on [Vercel](https://vercel.com) or any other platform that supports Next.js.
